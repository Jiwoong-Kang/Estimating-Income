### 1. EDA step 1: how to take a first look

- EDA uses **train only**. Judging from test leaks information and makes evaluation unfair. Test was only checked for matching format.
- pandas used for the first look:
  - `head()`: check that values loaded correctly
  - `info()`: dtypes and non-null counts per column
  - `select_dtypes()`: split numeric vs string columns for later plots/preprocessing
  - `nunique()`: how many distinct values per column
  - `pd.crosstab()`: counts of value pairs; useful to see if two columns carry the same information

### 2. Data traits from the first look

- 6 numeric features, 8 categorical, 1 target.
- `education` and `education-num` are one-to-one in the crosstab. **Putting the same info twice** lets the model reuse it; keep only one.
- `fnlwgt` is almost unique per row (21,648 levels). It is a census sample weight, not a person trait — decide separately whether to use it.
- `native-country` has 41 levels, so one-hot encoding expands columns a lot.

### 3. String dtypes in pandas 3

- Through pandas 2, string columns were `object`; **from pandas 3 they are `str`** (shown in `info()`).
- `select_dtypes(include="object")` still picks `str` for compatibility but warns (`Pandas4Warning`); a later version may return empty.
- Switched to `include="str"`. `requirements.txt` pins `pandas==3.0.6` so other environments match.
- **Takeaway:** do not ignore warnings even if today’s result looks fine. Categoricals could silently drop later. The warning often says how to fix it.

### 4. Lesson from a mistake: quote placement

- `print("Categorical Features: :, categorical_cols")` closed the quote after the variable name, so it printed the literal text, not the value.
- Everything inside quotes is a string. Put variables outside, separated by commas.

### 5. EDA step 2: ask why values are missing

- Counting missings is not enough. Ask whether **people with missings differ** from the rest — that chooses the treatment.
  - High-income rate with missing workclass/occupation: 10.4% vs 24.9% if present → missingness is informative.
  - native-country: 25.0% vs 24.1% → closer to random missingness.
- Three treatments and when to use them:
  - Drop rows / fill with the mode: when missing people are **similar** to the rest
  - Keep a separate `"Missing"` level: when they **differ**
- Another reason not to drop rows: test also has missings. At prediction time you cannot skip those people, so missing handling must be part of the model.
- Crosstabs of missingness: if workclass is missing, occupation always is. The 7 occupation-only missings were all `Never-worked` → no job to report, not refusal. Missings can have a logical reason.

### 6. EDA step 3: the accuracy trap on imbalanced data

- Only 24.08% are >50K, so a Dummy that always says <=50K gets 75.92% accuracy.
- That Dummy finds **zero** >50K cases and still looks accurate. Use F1, balanced accuracy, ROC-AUC, PR-AUC, and the confusion matrix together.
- Checked train/test label shares (24.08% vs 23.62%). Similar shares support expecting similar performance on test.
- Imbalance responses: `StratifiedKFold`, `class_weight="balanced"`, threshold tuning. At ~76:24, SMOTE-style oversampling is usually unnecessary.

### 7. EDA step 4: numerics need more than the mean

- Extended `describe()` with variance (`var`), skew, and zero rate.
- **Mean far from median signals a skewed distribution.** capital-gain: both groups have median 0 but means 4,006 vs 149 — a few large values pull the mean.
- **Similar means can hide different shapes.** Mean age with missing workclass (41.0) is close to others (38.4), but under-25 and 60+ are ~2× and ~4× more common — young and old cancel in the average.
- Exact caps like 99999, 99, 90 are likely **top-coding**, not typos. Do not delete them (159 people with capital-gain 99999 were 100% high income).
- When comparing groups, plot with `density=True`. A 3× size gap hides the smaller group if you plot raw counts.
- `np.log1p(x) = log(1 + x)`: log that works with zeros; shortens a long right tail. With ~95% zeros (capital-loss), effect is tiny (skew 4.59 → 4.31).
- Scale gaps and skew hurt k-NN, SVM, Perceptron, and linear models. Decision trees mostly ignore them (threshold splits only).

### 8. EDA step 5: categoricals and rare levels

- Repeated the same summary across features via `category_summary`; use `display()` inside loops.
- Strongest signal: marital status. Married-civ-spouse 44.7% high income vs Never-married 4.6%.
- **Rates on tiny groups are unreliable.** Married-AF-spouse was 43.5% but only 23 people. Rare levels waste one-hot columns and can overfit — consider grouping.
- relationship Husband: 13,192 of 13,193 male; Husband/Wife all married. Overlapping features **break Naive Bayes’s independence assumption** (same evidence counted multiple times).
- sex/race gaps reflect 1994 inequality in the data. The model will learn them; read the data critically.

### 9. EDA step 6: measuring association

| Metric | Use | Notes |
|---|---|---|
| Pearson correlation | numeric–numeric | Linear only; sensitive to extremes |
| Spearman correlation | numeric–numeric | Rank-based; catches nonlinear links; less sensitive to extremes |
| Cramér's V | categorical–categorical | 0–1; chi-square rescaled to 0–1 |

- capital-gain: Pearson 0.223 vs Spearman 0.278 — difference means a nonlinear link or extreme-value influence.
- No single dominant numeric (best education-num 0.33) → use several features together.
- fnlwgt vs target ≈ −0.009 → with step 4, grounds for dropping. **Backing one decision with several steps makes it persuasive.**
- Do not compare Cramér's V numbers directly to correlation coefficients — different scales/methods.
- Association is pairwise only; joint effects and causation are unknown.
