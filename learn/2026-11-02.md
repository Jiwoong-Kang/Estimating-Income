### 2. Bagging vs Random Forest

| | Bagging | Random Forest |
|---|---|---|
| 공통 | 부트스트랩 샘플로 트리 여러 개 → 다수결 | 같음 |
| 차이 | 분할할 때 (기본) 특징 전체를 볼 수 있음 | 분할할 때마다 **특징 일부만** 무작위 |

- 둘 다 “분산이 큰 모델(깊은 트리)을 여러 개 묶어 안정화”하는 앙상블.
- bias–variance 노트북에서 트리를 깊게 하면 과적합(분산↑)이 보였음 → 앙상블이 그다음 단계로 자연스러움.

### 3. 왜 회귀 배깅 / 단일 트리는 이 노트북에 안 넣었나

- 회귀 배깅: 분류 과제 본선과 거리가 있고, 트리만큼 효과가 도드라지지 않음.
- 단일 트리: 이미 `max_depth=15`로 튜닝·저장해 둠. 여기서는 **비교 기준 숫자만** 가져오면 됨.

### 5. 해석

- **앙상블 > 단일 트리**: 정확도·특히 ROC-AUC / PR-AUC가 크게 오름. 트리 여러 개로 분산을 줄인 효과.
- **Bagging vs RF**: 전반적으로 비슷.
  - F1·balanced accuracy → Bagging이 조금 우위
  - ROC-AUC / accuracy → RF가 아주 살짝 우위
  - RF는 FP를 더 줄이고(보수적), FN은 조금 더 많음
- 보고서 한 줄: Ensembles beat a single tree; Bagging and RF are close (Bagging edges F1, RF edges ranking metrics).
