# 2026-10-14

### 1. Why a preprocessing module (`src/preprocess.py`)

- Put EDA preprocessing decisions in one place; every model notebook calls these functions. → **Every model gets the same treatment, so comparison is fair.**
- Built piece by piece, checking each piece with `test.py` before moving on.

### 2. Preprocessing stages

| Stage | What it does | Tool |
|---|---|---|
| 1 | Split X/y; drop unused columns (fnlwgt, education) | `split_features_target` |
| 2 | Fill categorical missings with "Missing" | `SimpleImputer` |
| 3 | Expand categories to 0/1 columns (one-hot) | `OneHotEncoder` |
| 4 | Tidy numerics (log, scale) | `FunctionTransformer(np.log1p)`, `StandardScaler` |
| Bundle | Assign the right tool per column group | `ColumnTransformer` |
| Assemble | Chain preprocess + model | `Pipeline` |

- fnlwgt is a sample weight (how many people this row represents), unrelated to individual income. education is 1:1 with education-num — keep the numeric side only.

### 3. One-hot encoding: turning text into numbers

- Computers cannot compute on strings, so for each level make a “is this value?” column with 1/0.
- Do not use 1, 2, 3 labels — the model would invent a false order (“3 > 1”).
- Per original feature, a person has exactly one 1 among that feature’s columns (e.g. one of five race columns).
- 7 categoricals → **66 columns**. Levels appearing fewer than 50 times are grouped into one “infrequent” column via `min_frequency=50` (native-country 42 levels → 23 columns).
- Column names look like `feature_value` (e.g. `workclass_Missing`). Seeing `workclass_Missing` means imputation worked.

### 4. Tidying numeric features

- **StandardScaler:** rewrite each value as distance from the mean; mean 0, typical spread 1. Makes features with different ranges (age 17–90 vs capital-gain 0–99999) comparable. Needed for distance/scale-sensitive models (k-NN, SVM, …).
- **log1p:** shrinks large values more than small ones (like counting digits). Plain `log` fails at 0, so use `log1p` (0 → 0).
- Order for capital features: **log → scale**. Compress outliers first so scaling behaves.
- Log and scale change cell values only; **column count stays the same** (`one-to-one`). One-hot expands columns.

### 5. Why optional switches

- `scale`, `log_capital` are True/False switches (default True).
- Trees that only ask “age > 40?” get the same result with or without scaling/log → one function can serve different models.
- Comparing on/off results feeds the report’s “what helped.”
- `"passthrough"`: leave columns unchanged.
- `**preprocess_options`: collect `name=value` kwargs. `make_model_pipeline(model, scale=False)` passes `scale=False` into `build_preprocessor`.

### 6. Pipeline and ColumnTransformer

- **Pipeline:** run (name, transformer) pairs in list order.
- **ColumnTransformer:** (name, transformer, columns) triples; apply different tools per group and concatenate sideways. 3 numeric + 2 capital + 66 one-hot = **71 columns**.
- Names are labels we choose; the transformer does the work. Names prefix columns as `name__` (e.g. `numeric__age`, `capital__capital-gain`) so you can see which path they took.

### 7. fit, transform, and leakage

- `fit_transform` is built into scikit-learn estimators, not something we invented.

| Method | Role |
|---|---|
| `fit` | Learn from data (means, category levels, …) |
| `transform` | Apply those learned rules |
| `fit_transform` | Both at once |

- **Never `fit` on test.** Learn on train, then `transform` only. Fitting on test peeks at the exam — **data leakage**.
- Bundling preprocess + model in `make_model_pipeline` means `pipe.fit(X_train, y_train)` and `pipe.predict(X_test)` — accidentally fitting test becomes structurally hard.

### 8. First end-to-end run

- Preprocess + LogisticRegression (`max_iter=1000`): test accuracy **84.7%**, ~8 pp above Dummy (76.4%) → whole pipeline works.
- `max_iter`: max optimization steps; default 100 can warn.
- Imbalance means accuracy alone is not enough → next, `src/evaluate.py` adds ROC-AUC, F1, confusion matrix, etc.

### 9. Lessons from mistakes

- **Names from another file must be imported.** Forgot `CATEGORICAL_COLS` in `test.py` → “Undefined name”. Python scopes names per file.
- `"Function ... is not accessed"` is an editor (Pylance) hint, not a runtime error — a `_` helper unused yet in that file.
- One wrong value can silently break results. `">50k"` (lowercase) made every y = 0. → **Habit: visually check run output.**
