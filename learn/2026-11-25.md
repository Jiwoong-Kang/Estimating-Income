### 3. Metric definitions

| Metric | Definition |
|---|---|
| **accuracy** | Fraction of predictions that match the true label: (TP + TN) / all. Easy to read, but on imbalanced data a majority-only Dummy can look strong (~76% here). |
| **balanced_accuracy** | Average of recall for each class: (TPR + TNR) / 2. Treats the two classes more equally, so it is less fooled by the majority class. |
| **f1** | Harmonic mean of precision and recall for the positive class (`>50K`): 2 · precision · recall / (precision + recall). High only if you both find high-income people and avoid too many false alarms. Dummy F1 = 0. |
| **roc_auc** | Area under the ROC curve (true positive rate vs false positive rate across thresholds). Uses ranking scores (`predict_proba` or `decision_function`). 0.5 ≈ random; 1.0 ≈ perfect separation. |
| **average_precision** | Area under the precision–recall curve (PR-AUC). Emphasizes performance on the minority / positive class (`>50K`); often more informative than ROC-AUC under imbalance. |

Positive class in this project: income `>50K` (encoded as 1).
