### 2. AdaBoost vs Gradient Boosting

| | AdaBoost | Gradient Boosting |
|---|---|---|
| Idea | Raise **weights** on wrong samples → next weak learner focuses there | Add trees that reduce **residuals (errors)** |
| Base depth | **1** (decision stump, weak learner) | **3** (weak but more expressive than a stump) |
| learning_rate | (defaults) | **0.1** — how hard each tree is added |

### 3. Why we did not search hyperparameters (this is fine)

- Earlier models (Poly~Logistic): candidates + CV to pick a **final setting**.
- Post-clustering ensembles: goal is **method comparison**, so fix `n_estimators` etc.
- learning_rate need not be searched; `0.1` is a common start and often moves with `n_estimators`.
- Project Type 1 cares more about **comparison, interpretation, lessons** than top accuracy.
