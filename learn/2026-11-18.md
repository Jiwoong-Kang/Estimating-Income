### 2. 수업 내용과 MLP

MLP ≈ 다층 피드포워드 + 활성함수(ReLU) + 경사하강(`adam`) + 백프로프(라이브러리) + 분류 손실.
CNN은 별 트랙이라 Adult에는 사용하지 않음.

### 3. `solver` / 은닉층 튜닝

- `solver`: 가중치를 어떻게 업데이트할지. `adam` = 적응적 학습률의 확률적 경사하강. 데이터가 클 때 흔함.
- 은닉층 개수·크기는 **필수로 안 찾아도 됨**. 과제 목적은 방법 비교. `(64, 32)` 고정으로 충분.

### 4. ConvergenceWarning

- `max_iter`에 도달했는데 최적화가 덜 끝났다는 경고.
- 점수는 이미 나오므로 실패는 아님.
- `max_iter`만 키운다고 시험 성능이 항상 좋아지지는 않음.

### 5. max_iter 300 vs 500 (Test)

| 지표 | 300 | 500 |
|---|---|---|
| accuracy | **0.834** | 0.833 |
| balanced_accuracy | **0.760** | 0.742 |
| f1 | **0.638** | 0.617 |
| roc_auc | **0.882** | 0.878 |
| average_precision | **0.711** | 0.706 |

- 300 혼동 행렬: `[[11181, 1254], [1455, 2391]]`
- 500 혼동 행렬: `[[11369, 1066], [1654, 2192]]` — FP↓, FN↑ → F1 하락

해석: 더 오래 학습해도 **일반화가 자동으로 좋아지지 않음**. 과적합에 가까운 쪽으로 갈 수 있음.  
최종 보고/비교에는 **Test F1이 나은 300**을 쓰는 편이 낫다. (json을 300으로 다시 저장해 두면 일관됨)
