### 2. Direct decomposition vs indirect illustration

- Train scores do **not** contain numeric “bias” and “variance” fields.
- True decomposition (bias² + variance) fits regression / squared error better; rarely used with classification + F1.
- This notebook is an **estimate**: complexity ↔ train/CV pattern → “looks like high bias / high variance.”
- Be honest in the report: train vs CV curves **illustrate** the tradeoff (not a numeric decomposition).

### 3. Train / CV / Validation / Test

| Name | Meaning |
|---|---|
| Train score | Scored on the fold’s **training** rows |
| CV score | Scored on the fold’s **held-out** slice (`cross_validate`’s `test_score`) |
| Fixed validation file | **None**. CV folds act as temporary validation |
| Final Test | `adult.test` → `evaluate_on_test` (not used in this notebook) |
