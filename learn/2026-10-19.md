### 2. What Perceptron is

- A linear classifier that **nudges the boundary** using only misclassified points.
- No probabilities; only `decision_function` → already handled by `_positive_scores` in `evaluate.py`.
- If data are not cleanly linearly separable, it may not converge well or scores can be unstable (as discussed in class).

### 3. `random_state` / `max_iter`

- `random_state`: fix randomness for reproducible runs (e.g. 42). Not required for learning, but useful for reports.
- `max_iter`: max boundary updates. Too small → convergence warnings; set to 1000.
