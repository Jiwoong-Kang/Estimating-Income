### 2. 회귀를 분류에 쓰려면 임계값이 필요하다

- `LinearRegression.predict`는 0/1이 아니라 `0.7`, `-0.2` 같은 **실수**를 낸다.
- 그래서 래퍼로 감싼다.
  - `decision_function` = 실수 점수 그대로 → ROC-AUC, PR-AUC용
  - `predict` = `점수 >= 0.5`이면 1, 아니면 0 → accuracy, F1, 혼동 행렬용
- 기본 임계값은 0.5. 나중에 0.4 등으로 바꾸면 고소득을 더/덜 맞히는 쪽으로 조절할 수 있다.

### 3. `NotFittedError`에서 배운 점

- 래퍼의 `fit`이 안쪽 회귀만 학습하고, 래퍼 자신에 “학습됨” 표시(`classes_`처럼 끝이 `_`인 속성)를 안 남기면, scikit-learn이 **아직 학습 안 된 모델**로 본다.
- `pipe.fit`을 호출해도 `predict`에서 `NotFittedError`가 날 수 있다.
- 고치기: `fit` 안에서 `self.classes_ = np.array([0, 1])`처럼 표시를 남긴다.
- `evaluate.py`를 고친 뒤에는 **커널 재시작**하거나 import 셀을 다시 실행해야 한다. 이미 불러온 모듈은 자동으로 안 바뀐다.
- `BaseEstimator`, `ClassifierMixin`을 붙이는 이유: `cross_validate`가 모델을 복사(clone)할 때 필요하다.

### 5. 다항 회귀와 안쪽 Pipeline

- 다항 회귀 = **PolynomialFeatures(열 펼치기) + LinearRegression** 두 단계다.
- `make_model_pipeline` / `ThresholdingRegressor`에는 모델 자리 하나뿐이라, 두 단계를 **안쪽 `Pipeline`으로 한 덩어리**로 묶는다.
- 이 Pipeline은 “선형과 다항을 비교하려고” 넣은 게 아니라, **다항만 할 때도** 필요하다.
- `include_bias=False`: 상수항 열을 다항 쪽에서 또 만들지 않는다. (회귀가 절편을 따로 가짐)
- degree=2는 전처리 후 ~71열 위에 2차 항/곱을 만들어 열이 약 2천 개대로 늘어난다. degree=3은 더 커서 오늘은 안 했다.

### 7. import / 커널에서 배운 점

- `evaluate.py`에 클래스를 옮긴 뒤 `ImportError`가 나면: 저장 전 실행, 또는 커널이 옛 모듈을 들고 있는 경우가 많다.
- 커널 재시작: 노트북 위 Restart / 명령 팔레트 `Notebook: Restart Kernel`.

- 터미널에서는 import가 되는데 노트북만 실패하면, 파일은 정상이고 **커널 상태** 문제인 경우가 많다.
