### 2. Regression for classification needs a threshold

- `LinearRegression.predict` returns continuous scores like `0.7`, `-0.2`, not 0/1.
- Wrap it:
  - `decision_function` = raw scores → ROC-AUC, PR-AUC
  - `predict` = `score >= 0.5` → 1 else 0 → accuracy, F1, confusion matrix
- Default threshold 0.5. Later 0.4 etc. can trade more/fewer high-income predictions.

### 3. Lesson from `NotFittedError`

- If the wrapper’s `fit` trains only the inner regressor and never sets a “fitted” marker (attributes ending in `_` like `classes_`), scikit-learn treats it as **unfitted**.
- Even after `pipe.fit`, `predict` can raise `NotFittedError`.
- Fix: in `fit`, set e.g. `self.classes_ = np.array([0, 1])`.
- After editing `evaluate.py`, **restart the kernel** or re-run the import cell — already-imported modules do not auto-update.
- `BaseEstimator` + `ClassifierMixin`: needed so `cross_validate` can clone the model.

### 5. Polynomial regression and an inner Pipeline

- Polynomial = **PolynomialFeatures + LinearRegression**.
- `make_model_pipeline` / `ThresholdingRegressor` have one model slot, so wrap both steps in an **inner `Pipeline`**.
- That Pipeline is required for polynomial alone, not just for comparing linear vs poly.
- `include_bias=False`: do not add another constant column (the regressor has its own intercept).
- degree=2 expands ~71 post-preprocess columns to ~2k with interactions. degree=3 is larger — skipped today.
